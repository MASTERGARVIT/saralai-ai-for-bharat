# SaralAI

**Team:** Silent Watcher  
**Hackathon:** AWS AI for Bharat Hackathon  
**Track:** AI for Communities, Access & Public Impact  

## Overview
SaralAI is a multilingual, AI-powered conversational assistant that helps citizens discover and understand government schemes, skilling programs, and public opportunities using natural language and voice input.

## Problem
Citizens struggle to access and understand government schemes due to fragmented information, complex language, and lack of personalized, vernacular guidance.

## Solution
SaralAI provides:
- Vernacular-first text and voice interaction
- Personalized eligibility-based recommendations
- Simple, actionable step-by-step guidance
- Trusted responses grounded in official sources
